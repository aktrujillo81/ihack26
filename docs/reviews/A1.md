## Build round (Backend, 2026-11-14)
Built on `feat/auth-roles`; no feat/auth-prep files touched. Build-time choices
and deviations (also in `docs/contracts.md`):
- `/api/auth` serves only sign-in/email, sign-out, get-session (deny by default, 404 otherwise).
- Better Auth's rate limiter covers only HTTP requests (it runs in the router's
  onRequest in 1.7.23), so `signInWithPassword` enforces its own 5/min per
  `cf-connecting-ip`. The two paths have separate buckets.
- A session-create hook refuses a session for an account without one active
  membership and a region, and caps the row at 12 hours (Better Auth's
  `rememberMe: false` would otherwise give 24 hours).
- `disableSessionRefresh: true`: sessions are a fixed 12 hours.
- `disableOriginCheck: false` set explicitly: Better Auth skips the Origin
  check under NODE_ENV=test by default.
- Auth table timestamps are timestamptz (Better Auth's generator uses
  timestamp without time zone).
- `memberships` also has unique (id, organization_id), needed as the target of
  the composite FK.
- Open for Security: `get-session` and `sign-in` response bodies include the
  session token (Better Auth default); the cookie is HttpOnly.
